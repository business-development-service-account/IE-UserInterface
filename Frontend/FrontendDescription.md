I need a frontend for my software. This frontend will serve as an interaction platform for the enduser of my ai system. It will consist of three parts: Projects, Collections, Settings. The main part of this frontend will be a chat interface where the user can work on projects together with an ai agent system. The other two parts are the settings area to edit basic values and functionalities and the Collections connector where the user can specify top which data silos of the rag system he wants to be connected to.
Now I describe the general structure of the frontend and its functionalities:
- Projects: Left site vertically arranged to the right edge all Projects with a button to create a new project. Right site Project Name in the upper left corner. Below a chat interface with the message history and an input field with a send message button. Below this chat interface a vertically divided area. Left site is Skills, where the user can edit YAML templates consiting of a name, short description and the main part with the content. It always starts with a starting template where the user sees Name and then a displayed text like give it a easy to understand name. Under that Description: Give it a short description what this template is for and the same with main content. The displayed text vanishes when the user starts creating his text in the corresponding field. Additional to the initial template there is a button that creates a new basic template.
Next to the Skills area is the file area. Here the user can drop/ upload files the AI Agent has access to and also the ai agent will be able to save files.
Next to the name of the project, to the right site, the user can decide which functionalities are available to the agent, like web search, etc. But what functionalities exist is set in the settings area. In the project area its just a drop down that loads all existing tools, the user chooses one and then a new drop down with yet not chosen tools appears. 
In the Collections area a user can connect to existing collections or create one. So the user sees a "Connect a Collection" with a drop down where existing collections appear and a "create a collection" that lets a template appear where the user can input a Name and a description and then click create.
